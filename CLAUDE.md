## gstack

Use the `/browse` skill from gstack for all web browsing.
Never use `mcp__claude-in-chrome__*` tools.

## Skill Routing

Use gstack skills when they fit the task:
- `/office-hours` for product framing and scoping
- `/autoplan` for reviewed implementation plans
- `/review` for code review
- `/qa` for browser-based QA and bug finding
- `/ship` for pre-PR release workflow
