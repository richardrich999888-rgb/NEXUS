## Getting Started

1. **Sign up** at [nexus-agp.io/signup](https://nexus-agp.io/signup)
2. **Get API key** from the dashboard
3. **Install SDK**: `pip install agp-os`
4. **Deploy agents** with governance enabled

```python
from agp_os import GovernanceClient

client = GovernanceClient(api_key="your-key")
result = client.evaluate_action(
    agent_id="agent-1",
    action="send_email",
    context={"recipient": "user@example.com"}
)
```
