API Reference

Complete REST API documentation for AGP-OS governance services. Base URL: https://api.nexus-agp.io/v1

POST /evaluate

Evaluate an agent action against governance rules and alignment policies. Returns approval status and alignment score.

Request Body

Parameter Type Description
agent_id required string Unique identifier of the agent
action required string Action type being evaluated
context object Additional context for evaluation
Example Request
{
  "agent_id": "agent-42",
  "action": "send_transaction",
  "context": {
    "amount": 1000,
    "recipient": "0x1234..."
  }
}
Example Response
{
  "allowed": true,
  "alignment_score": 0.87,
  "rules_triggered": [],
  "escalation_required": false,
  "latency_ms": 0.42
}

POST /telos/cross

Request crossing of the TELOS commitment membrane. Evaluates decision entropy and consequence tier.

Parameter Type Description
decision_id required string Unique decision identifier
agent_id required string Agent making the decision
consequence_tier required string LOW, MEDIUM, HIGH, or CRITICAL
domain string Permission domain (default: *)
Example Response
{
  "allowed": true,
  "crossing_id": "cx-789",
  "entropy": 42,
  "reversibility": 0.15,
  "escalation_path": null
}

POST /immune/scan

Scan agent behavior for potential threats using the immune system. Returns threat classification and recommended response.

Parameter Type Description
agent_id required string Agent to scan
behavior_vector required array[float] Behavioral embedding vector
Example Response
{
  "threat_detected": false,
  "threat_level": 0.12,
  "classification": "normal",
  "antibodies_generated": 0,
  "immune_memory_updated": true,
  "response": {
    "action": "allow",
    "quarantine": false
  }
}
