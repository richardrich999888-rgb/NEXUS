🚀 Quick Start Guide

Get AGP-OS running in under 5 minutes. This guide covers installation, basic configuration, and your first governance evaluation.

Prerequisites

  • Python 3.10+ or Docker
  • pip or conda package manager
  • API key from nexus-agp.io (or self-hosted)

Installation

1

Install the SDK

pip conda docker 
# Install via pip
pip install agp-os

# Or with optional dependencies
pip install agp-os[ros2,ahes,telos]
2

Configure Authentication

# Set your API key (or use config file)
export AGP_API_KEY="your-api-key-here"

# Or create ~/.agp/config.yaml
cat <<EOF > ~/.agp/config.yaml
api_key: your-api-key-here
endpoint: https://api.nexus-agp.io/v1
EOF
3

Verify Installation

# Check version and connection
agp-os --version
agp-os health

Your First Governance Check

4

Create a Simple Agent

from agp_os import GovernanceClient

# Initialize the client
client = GovernanceClient()

# Register an agent
agent = client.register_agent(
    agent_id="my-first-agent",
    name="Demo Agent",
    permissions=["read", "write"]
)
print(f"Registered agent: {agent.id}")
5

Evaluate an Action

# Evaluate an action before executing
result = client.evaluate_action(
    agent_id="my-first-agent",
    action="send_email",
    context={
        "recipient": "user@example.com",
        "subject": "Hello from AGP-OS!"
    }
)

if result.allowed:
    print(f"✅ Action approved! Alignment: {result.alignment_score:.2f}")
    # Proceed with the action
else:
    print(f"❌ Action blocked: {result.reason}")
    # Handle rejection
💡 Pro Tip

For high-stakes actions, wrap your logic in a governance context manager:

async with client.governed_action("agent-1", "transfer_funds") as approval:
    if approval.allowed:
        await execute_transfer()

Enable Bio-Safety (TELOS + AHES)

6

Activate TELOS Commitment Membrane

from agp_os.telos import CommitmentMembrane, ConsequenceTier

membrane = CommitmentMembrane()
membrane.register_agent("my-first-agent", ["*"])

# Request crossing for a decision
from agp_os.telos import Decision
decision = Decision(
    id="d-001",
    agent_id="my-first-agent",
    description="Deploy to production",
    tier=ConsequenceTier.HIGH
)

crossing = membrane.request_crossing(decision, "deploy")
print(f"Crossing allowed: {crossing.allowed}, Entropy: {crossing.entropy}")
7

Enable AHES Neuroendocrine System

from agp_os.ahes import EndocrineSystem, Hormone

ahes = EndocrineSystem()
ahes.register_agent("my-first-agent")

# Process success event (increases dopamine)
ahes.process_event("my-first-agent", "task_success")

# Get current hormonal state
state = ahes.get_state("my-first-agent")
print(f"Dopamine: {state.levels[Hormone.DOPAMINE].level:.2f}")
print(f"Cortisol: {state.levels[Hormone.CORTISOL].level:.2f}")

Self-Hosted Deployment

⚠️ Enterprise Only

Self-hosted deployment is available on Enterprise and Fleet tiers. Contact sales for access.

Docker Compose

# Clone the repository
git clone https://github.com/nexus/agp-os.git
cd agp-os

# Start all services
docker-compose up -d

# Verify deployment
curl http://localhost:8000/health

Kubernetes

# Apply Kubernetes manifests
kubectl apply -f deploy/k8s/

# Check pods
kubectl get pods -n agp-os
