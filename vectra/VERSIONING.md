## Invariants (Immutable)

### 1. Losslessness Invariant
```
∀ x ∈ ValidInput: decode(encode(x)) == x
```
Any artifact produced by VECTRA v1.x **MUST** decode to the exact original bytes.

### 2. Determinism Invariant
```
∀ x, t₁, t₂: encode(x, t₁) == encode(x, t₂)
```
The same input **MUST** produce bit-identical artifacts regardless of when or where encoding occurs.

### 3. Integrity Invariant
```
∀ artifact: SHA256(decode(artifact)) == artifact.integrity.payload_hash
```
Decoded output **MUST** match the embedded integrity hash.

## Compatibility Guarantee

### Forward Compatibility
- Artifacts generated by VECTRA v1.0 **WILL** decode correctly in all future v1.x releases.
- Breaking changes require a major version bump (v2.0).

### Version Detection
- All artifacts contain `VERSION_ID = 0x56454354_52410001` (VECTRA v1)
- Version mismatch **MUST** produce a clear error, never silent corruption.

### Artifact Header
```
Bytes 0-3: Magic "VCTR"
Bytes 4+:  Bincode-serialized Artifact
```

## Change Policy

### Allowed Changes (v1.x)
- Bug fixes that do not alter valid behavior
- Performance optimizations to existing logic
- Additional test coverage
- Documentation improvements

### Prohibited Changes (v1.x)
- Altering encode output for any valid input
- Changing artifact binary format
- Modifying integrity hash algorithm
- Breaking backward compatibility

### Version Bump Required
| Change Type | Version Impact |
|-------------|----------------|
| Bug fix (non-breaking) | v1.0.x patch |
| New optional feature | v1.x.0 minor |
| Artifact format change | v2.0.0 major |
| Algorithm change | v2.0.0 major |

## Certification

Any VECTRA release claiming v1.x compatibility **MUST**:

1. Pass all v1.0 test vectors
2. Round-trip all v1.0 reference artifacts
3. Maintain determinism across builds
4. Preserve integrity verification
