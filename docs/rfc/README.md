## RFC Process

### Status Definitions

| Status | Meaning |
|--------|---------|
| Draft | Initial specification, subject to change |
| Proposed | Ready for review and feedback |
| Accepted | Approved for implementation |
| Final | Stable specification, no changes expected |
| Deprecated | Superseded by newer RFC |

### Creating New RFCs

1. Create file `RFC-NNNN-Title.md` in `docs/rfc/`
2. Use next available RFC number
3. Follow existing RFC format
4. Update this index
