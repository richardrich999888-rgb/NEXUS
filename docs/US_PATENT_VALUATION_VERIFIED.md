# HONEST CAVEATS

1. **Patents not yet filed.** Value is *potential* — actual value requires filed and granted patents.
2. **Software patent risk.** US §101 (Alice decision) makes software patents harder to obtain. Strong machine/transformation claims help.
3. **Single inventor.** Enforcement requires capital ($1M–$5M for litigation). Contingency firms can reduce this.
4. **No revenue.** Pre-revenue company patents are valued lower by acquirers.
5. **Grant timeline.** US patent prosecution takes 2–4 years on average.
