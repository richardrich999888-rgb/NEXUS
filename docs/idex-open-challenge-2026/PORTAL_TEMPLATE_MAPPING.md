# iDEX Portal Template Mapping

The downloaded iDEX portal templates map to the proposal package files as follows:

| Portal template | Extracted title | Package file |
| --- | --- | --- |
| Annexure - 1 | Proposed Solution Template (Open Challenge) | `PPS_SYNTRIASS.md` |
| Annexure - 2 | Proposed Technical Solution (Detailed) | `PTS_SYNTRIASS.md` |
| Annexure - 3 | Technology, Product, Commercial Advantages, Capabilities & Competencies | `PSB_SYNTRIASS.md` |
| Annexure - 4 | Applicant's Resume and Relevant Information related to solution | `AD_SYNTRIASS.md` |

Supporting files not present in the portal templates:

- `evidence.md`: test evidence, code references, demo script, TRL caveats.
- `budget.md`: 12-month milestone budget up to Rs. 1.5 crore.

Before portal upload, replace all placeholders for contact details, CIN, DPIIT recognition, registered office, and authorized signatory.
