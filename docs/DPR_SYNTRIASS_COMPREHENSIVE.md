# PART 3: INTELLECTUAL PROPERTY PORTFOLIO

## 3.1 Patent Families

### Family A: Content-Addressed Computation (PCU)

**Core Innovation:** Computation with deterministic identity derived from `code_hash + input_hashes + parameters + principal_identity`.

**Claims:**
- Deterministic computation ID enabling caching, routing, verification
- Code-to-data routing (computation moves to data, not vice versa)
- Content-hash-bound licensing (unforgeable)

**Implementation:** `nexus-pcu/src/pcu.rs`, `nexus-pcu/src/routing.rs`

### Family B: Algebraic Causal Infrastructure

**Core Innovation:** Data structures with mathematically-proven merge properties (idempotent, commutative, deterministic) combined with Merkle provenance.

**Claims:**
- Causal Tensor with vector clock + Merkle provenance
- Conflict-free distributed merge
- Universal State Object (USO) unifying DB/cache/queue/file

**Implementation:** `nexus-core/src/causal.rs`, `nexus-pcu/src/uso.rs`

### Family C: Execution Gate Architecture

**Core Innovation:** Single choke point for all computation; execution blocked without guard approval; no proof/cache on deny.

**Claims:**
- ExecutionGuard trait with check() before any run
- CompositeGuard with ordered, first-Deny-wins semantics
- Production executor requires guard (enforced at compile time)

**Implementation:** `nexus-executor/src/guard.rs`, `nexus-executor/src/executor.rs`

### Family D: TELOS Commitment Membrane

**Core Innovation:** Bio-inspired membrane where decisions cost entropy, high-consequence actions require external attestation.

**Claims:**
- Entropy-based irreversibility (crossing cost)
- Consequence tiers with escalation paths
- Authority delegation chains

**Implementation:** `telos-protocol/`, `agp-core/src/telos/`

### Family E: AHES Neuroendocrine System

**Core Innovation:** 8-hormone system regulating AI behavior with bio-realistic dynamics (decay, saturation, circadian).

**Claims:**
- Multi-hormone state affecting decision-making
- Receptor saturation and adaptation (allostasis)
- Stress-immune coupling

**Implementation:** `agp-core/src/ahes/`, `homeostasis-engine/`

### Family F: Artificial Immune System

**Core Innovation:** Self/non-self discrimination for AI agents with innate + adaptive layers.

**Claims:**
- Innate immunity (pattern recognition)
- Adaptive immunity (T-cells, antibodies, memory)
- Defection detection (multi-agent collusion)

**Implementation:** `agp-core/src/immunity/`, `multi-asi-immune/`

### Family G: Developmental Stage Gates

**Core Innovation:** Capability unlocking based on demonstrated maturity (Embryonic → Adult).

**Claims:**
- Stage-based capability gates
- Maturity verification before capability grant
- Regression prevention

**Implementation:** `developmental-gates/`, `nexus-executor/src/guards/`

### Family H: Hybrid Classical-PQC Signatures

**Core Innovation:** Defense-in-depth signature verification where EITHER classical or post-quantum passing is sufficient.

**Claims:**
- HybridSignature with Ed25519 + ML-DSA
- Either-or verification logic
- Future-proof cryptographic binding

**Implementation:** `nexus-pcu/src/pqc.rs`
